# طريقة العمل والنقل المحلي

## قاعدة المشروع

المجلد `phone-pc-remote` هو مصدر الحقيقة. أي نقل إلى جهاز آخر يتم عبر ZIP واحد فقط.

## إنشاء آخر نسخة مضغوطة

من داخل مجلد المشروع:

```powershell
.\make-latest-zip.ps1
```

الناتج:

```text
releases/phone-pc-remote-latest.zip
```

## النقل إلى حاسوب آخر

1. انسخ ملف ZIP إلى USB أو هارد خارجي.
2. انقل الملف إلى الحاسوب الجديد.
3. فك الضغط.
4. افتح مجلد المشروع.
5. تابع العمل.

## ما لا ندخله داخل ZIP

- `releases/`
- `.git/`
- `node_modules/`
- `build/`
- `dist/`
- `.gradle/`
- `.idea/`
- ملفات مؤقتة.

## ملاحظة

يمكن استخدام Git محلي فقط لاحقا إذا أردنا تاريخ تعديلات، لكنه ليس مطلوبا ولا يحتاج إلى إنترنت.
