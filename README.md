# Qareeb Control

تطبيق محلي بالكامل يحول الهاتف إلى لوحة تحكم قريبة للحاسوب: ماوس، كيبورد لحظي، ريموت ميديا، اختصارات، وإدارة أمان أساسية داخل شبكة Wi-Fi.

الاسم التقني القديم للمجلدات والحزم يبقى `phone-pc-remote` مؤقتا حتى لا تنكسر مسارات البناء والنقل، أما اسم المنتج المعتمد فهو `Qareeb Control`.

## المبدأ

- لا GitHub ولا Cloud ولا Firebase.
- كل الملفات داخل هذا المجلد.
- النقل بين الحواسيب يتم عبر ملف ZIP واحد فقط.
- اتصال الهاتف بالحاسوب يتم داخل الشبكة المحلية.
- لا يتم إرسال بيانات التحكم إلى الإنترنت.

## بنية المشروع

```text
phone-pc-remote/
  mobile-app/
  desktop-server/
  website/
  docs/
  releases/
  README.md
  CHANGELOG.md
  VERSION.txt
  make-latest-zip.ps1
```

## المكونات

- `mobile-app/`: تطبيق الهاتف. البداية ستكون Android Native.
- `desktop-server/`: برنامج الحاسوب المحلي. البداية ستكون Windows + Python.
- `website/`: موقع دعم محلي ثابت يشرح التحميل، التشغيل، الأمان، وحل المشاكل.
- `docs/`: خطة العمل، التصميم التقني، الأمان، وطريقة النقل المحلي.
- `docs/PRODUCT_STRATEGY.md`: معيار المنتج العالمي وخارطة التحسين.
- `releases/`: يحتوي آخر ملف مضغوط رسمي للمشروع.

## طريقة العمل المحلية

1. نعدل الملفات داخل هذا المجلد.
2. نختبر السيرفر وتطبيق الهاتف محليا.
3. عند نهاية الجلسة نشغل:

```powershell
.\make-latest-zip.ps1
```

4. ينتج الملف:

```text
releases/phone-pc-remote-latest.zip
```

هذا الملف هو النسخة التي ننقلها إلى أي حاسوب آخر.

## الاتصال بين الهاتف والحاسوب

النسخة الحالية تستخدم بروتوكولا محليا بسيطا:

```text
Android App <--- JSON over local TCP ---> Desktop Server
```

اخترنا TCP المحلي في البداية لأنه يمكن تنفيذه بدون مكتبات خارجية:

- Python على الحاسوب عبر المكتبة القياسية.
- Android عبر `java.net.Socket`.

يمكن إضافة WebSocket لاحقا إذا احتجنا واجهات أو تكاملات أوسع.

## النسخة المستهدفة الآن

نسخة تجريبية مستقرة:

- اتصال محلي بين الهاتف والحاسوب.
- اقتران عبر رمز أمان.
- ماوس وتراكباد.
- كيبورد مباشر تظهر ضغطاته في الحقل المحدد على الحاسوب.
- أزرار ميديا.
- اختصارات مثل Copy و Paste و Alt+Tab.
- إدارة أجهزة موثوقة وإيقاف/إعادة تفعيل التحكم.
- أوامر طاقة محمية بتأكيد.
- موقع دعم محلي.
- ملف ZIP واحد لنقل آخر نسخة.
