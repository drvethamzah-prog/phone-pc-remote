# Mobile App

هذا المجلد يحتوي مشروع تطبيق Android أولي لمنتج `Qareeb Control`. تبقى الحزمة التقنية `com.phonepcremote` كما هي مؤقتا حتى لا تنكسر إعدادات البناء.

## الحالة الحالية

في `0.34.0-usb-network-policy` أضيف وضع USB network تجريبي فقط للشبكات التي
يعرضها Android 12+ للتطبيق، دون رجوع إلى Wi-Fi في وضع USB فقط. هذا لا يعني
أن USB tethering المعتاد يعمل على كل هاتف؛ لم يختبر الكابل الفعلي بعد.
تفاصيل القيود وخطة الاختبار في `docs/USB_NETWORK.md`.

في `0.33.0-english-default` الإنجليزية هي الافتراضية للتثبيت الجديد، دون تغيير
لغة اختارها المستخدم صراحة. متاح حاليا English والعربية ولغة النظام؛ لغات نافذة
الحاسوب الإضافية لا تمثل ترجمات Android. هذا القرار يحل محل ملاحظة العربية
الافتراضية في وصف النسخ التاريخية أدناه. لا تتغير لغة كيبورد الهاتف.

النسخة `0.32.0-local-qr` تضيف ماسح QR محليا وتأكيد الحاسوب قبل استيراد
العنوان والبصمة والتذكرة المؤقتة. لا يشغّل QR حاسوبا مطفأ أو سيرفرا متوقفا،
ولا ينقل التحكم عبر الإنترنت. التفعيل وفحص الكاميرا الفعلي مؤجلان حتى
عودة المستخدم قرب الجهاز؛ راجع `docs/QR_PAIRING.md`.

النسخة `0.31.0-pinned-tls` تضيف خيار بصمة شهادة الحاسوب في شاشة الأجهزة.
بعد حفظ بصمة SHA-256 من الحاسوب مباشرة، تتطلب جميع اتصالات TCP شهادة مطابقة
وTLS 1.2 أو أحدث، دون رجوع صامت للنقل غير المشفر. لا تفعل الخيار مع سيرفر
يعمل بالوضع القديم؛ يلزم تشغيله صراحة بـ `--tls`. لم تُرحّل جلسة المستخدم
ولا إعدادات بدء التشغيل تلقائيا. دليل المرحلة: `docs/PINNED_TLS.md`.

النسخة `0.30.0-local-ipv6` تضيف إلى استعادة الاتصال مسارا محليا عبر IPv6: يحفظ التطبيق عناوين الحاسوب بعد اتصال ناجح، ثم يختبرها عند إعادة الاتصال قبل IPv4 مع التحقق من سر الاقتران. تحتاج السيرفر المحدث؛ لا تحذف الاقتران. تبقى جميع الاتصالات محلية ولا يستخدم التحكم بيانات الهاتف أو عنوانا عاما. المسار لا يتجاوز عزل الشبكة، ولا يمثل تشفيرا للنقل أو اكتشافا أوليا عبر IPv6.

النسخة `0.27.0-media-remote` تعيد تصميم الوسائط كـريموت: تشغيل دائري مركزي، السابق والتالي، مجموعة صوت عمودية، واختصارات بأيقونات. أزرار الريموت تستخدم أوامر السيرفر نفسها، دون إضافة تحكم طاقة إلى شاشة الوسائط.

النسخة `0.26.0-polished-devices` تضيف شاشة أجهزة محسنة وأزرارا ثانوية بإطار وصفوف إدارة بأيقونات وتشخيصا قابلا للطي. خيار لغة الواجهة موجود في الأجهزة والإعدادات: العربية، الإنجليزية، أو لغة النظام؛ لا يغيّر لغة كيبورد الهاتف أو بيانات الاقتران. تبقى العربية الافتراضية للحفاظ على تجربة المستخدم الحالية.

تم إنشاء مشروع Android قابل للاستيراد في Android Studio:

- Gradle project داخل `mobile-app/`.
- تطبيق واحد داخل `app/`.
- Activity رئيسية: `app/src/main/java/com/phonepcremote/MainActivity.java`.
- ثلاث شاشات: التحكم، الوسائط، والأجهزة. إعدادات IP والمنفذ والاقتران داخل الأجهزة.
- يتعرف التطبيق على Android Emulator ويملأ `10.0.2.2` تلقائيا عند عدم وجود IP محفوظ.
- زر `بحث` لاكتشاف السيرفر تلقائيا داخل الشبكة المحلية.
- زر `محاكي` وزر `اختبار سريع` لتسهيل التجربة على Android Emulator.
- حفظ `deviceId`, آخر IP/Port، و token محليا عبر `SharedPreferences`.
- إخفاء قيمة token عند عرض JSON الاستجابة داخل واجهة التطبيق.
- اتصال TCP محلي برسائل JSON بسطر واحد لكل رسالة.
- تراكباد يرسل `mouse_move` ونقرة يسار، ويدعم تمرير بإصبعين.
- أزرار نقر يمين ويسار، وتمرير بإصبعين على التراكباد.
- الماوس وكيبورد الهاتف الأصلي في الشاشة نفسها، دون زر إرسال نص. يمكن إخفاء الكيبورد لتوسيع التراكباد.
- إرسال النص أثناء تكوين الكلمة في IME، والتعامل مع التصحيح والحذف دون تكرار الكلمة عند تأكيدها.
- شريط Ctrl وAlt وTab وEsc وEnter والحذف، مع إيقاف/استئناف التحكم في رأس الشاشة.
- البحث الذكي: إذا فشل بث UDP، يفحص التطبيق نفس شبكة Wi-Fi عبر TCP على المنفذ `8765`.
- أزرار اختصارات وميديا.
- أزرار إدارة: عرض الأجهزة الموثوقة، إعادة تفعيل التحكم، تغيير رمز الاقتران، وحذف هذا الهاتف من الثقة.
- قسم الطاقة: إطفاء الحاسوب بعد تأكيد واضح، وإلغاء الإطفاء المجدول.
- منزلق لحساسية المؤشر وخيار فتح الكيبورد عند الاتصال، داخل الإعدادات.
- زر `control_stop` لإيقاف التحكم.

## ملاحظة أدوات البناء

تم تثبيت أدوات Android محليا لهذا المشروع:

- JDK 17.
- Android Studio.
- Android SDK داخل `.android-sdk/`.
- `platform-tools` وفيها `adb.exe`.
- `platforms;android-35`.
- `build-tools;35.0.0`.

ملف `local.properties` يشير إلى مسار الـ SDK المحلي على هذا الجهاز. هذا الملف مستبعد من ZIP الرسمي لأنه مسار خاص بالجهاز.

## البناء

بعد فتح هذا المجلد في Android Studio:

```text
mobile-app/
```

نفذ Sync ثم Build APK من Android Studio. تم أيضا اختبار البناء محليا وإنتاج APK تجريبي في `app/build/outputs/apk/debug/app-debug.apk`. توجد نسخة جاهزة للنسخ إلى الهاتف في `../releases/phone-pc-remote-android-debug.apk`. وعند إنشاء ZIP الرسمي، تضاف نسخة داخل `android-apk/phone-pc-remote-android-debug.apk`.

للبناء من سطر الأوامر باستخدام Gradle المحلي في جذر المشروع:

```powershell
cd C:\developings\phone-pc-remote
.\.gradle-local\gradle-8.9\bin\gradle.bat -p mobile-app assembleDebug --no-daemon
```

أو إذا كان Gradle مثبتا عالميا:

```powershell
cd mobile-app
gradle assembleDebug
```

## اختبار المحاكي

تم اختبار التطبيق على Android Emulator باسم `PhonePCRemote_API35` باستخدام Android 15 / API 35. نتيجة الاختبار:

- تثبيت APK نجح.
- تشغيل `MainActivity` نجح.
- السيرفر يرد على اكتشاف UDP على نفس المنفذ `8765` بدون كشف رمز الاقتران.
- الاقتران مع السيرفر المحلي نجح عبر عنوان المحاكي `10.0.2.2:8765`.
- السلوك الجديد يملأ عنوان المحاكي تلقائيا ويدعم زر اختبار سريع.
- عرض الاستجابة يخفي قيمة `token` كـ `hidden`.
- تم اختبار سحب التراكباد، نقر الماوس، وPreset `سريع` على المحاكي.
- أوامر `Ping`, `Status`, نقر الماوس، والتمرير وصلت للسيرفر في وضع `--dry-run-controls`.
- لم تظهر Crash في `logcat` أثناء الاختبار.

تم حفظ لقطة شاشة وملفات UIAutomator داخل ../releases/ كأدلة اختبار محلية.

## التشغيل المتوقع

1. شغل Desktop Server على الحاسوب:

```powershell
cd desktop-server
python .\src\server.py
```

2. افتح التطبيق على الهاتف.
3. اضغط `بحث` ليملأ التطبيق IP والمنفذ تلقائيا، أو أدخل IP الحاسوب والمنفذ `8765` يدويا.
4. أدخل رمز الاقتران الظاهر في السيرفر.
5. اضغط اقتران.
6. بعد نجاح الاقتران استخدم التراكباد والكيبورد والميديا.
7. حدد مربع النص على الحاسوب ثم اكتب من كيبورد الهاتف. زر الكيبورد في شريط الأدوات يفتحه أو يخفيه.
8. من قسم الإدارة يمكن عرض الأجهزة الموثوقة، تغيير رمز الاقتران، إيقاف/تشغيل التحكم، أو حذف هذا الهاتف.
9. من قسم الطاقة في الأجهزة يمكن جدولة إطفاء الحاسوب بعد تأكيد، أو إلغاء الإطفاء قبل انتهاء المهلة.

## اختبار الكيبورد الجديد

النسخة `0.25.0-live-dashboard` تتضمن `RemoteKeyboardInput` لربط محرر Android الأصلي، و`LiveTextDelta` لاستخراج فروق النص. يحتفظ الهاتف بسياق قصير فقط، ويمسحه عند تغيير هدف الكتابة أو توقف التحكم. لا تسجل النصوص في سجل التطبيق.

بعد بناء `assembleDebug assembleDebugAndroidTest` وتثبيت التطبيق وAPK الاختبارات على المحاكي:

```powershell
python mobile-app/tools/test_native_dashboard.py
```

يشغّل الاختبار سيرفرًا معزولًا على loopback بمنفذ مؤقت وتخزين مؤقت ولوحة مفاتيح تسجيل فقط. يفحص التكوين، التأكيد، العربية، التصحيح، الحذف، إيقاف/استئناف التحكم والتنقل، ثم يعيد تفضيلات المحاكي. لا يرسل ضغطات فعلية إلى Windows ولا يغير أجهزة السيرفر الحقيقي الموثوقة. خيار `--preview` يبقي الواجهة مدة أقصاها خمس دقائق للفحص البصري.

اختبارات 2026-10-07: نجحت 35 نقطة تحقق على Android API 35 و12 حالة لفروق النص، مع اختبار نقر حرفين وحذف حرف على Gboard. اختبار لوحة Samsung على الهاتف الفعلي ما زال مطلوبًا، كما لم يختبر مسار المعاينة الكتابة داخل محرر Windows فعلي.

الأيقونات من Lucide 0.468.0 ومضمّنة محليًا؛ الرخصة في `LUCIDE_LICENSE.txt`. أداة `tools/import_lucide_icons.py` تعيد توليد Android vectors من المصدر المثبت، ولا يحتاج التطبيق الإنترنت لتحميلها.

## البروتوكول

```json
{"type":"ping"}
```

```json
{"type":"hello","deviceId":"...","deviceName":"...","pairingCode":"..."}
```

```json
{"type":"mouse_move","deviceId":"...","token":"...","dx":10,"dy":-4}
```
